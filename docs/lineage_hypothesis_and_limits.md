# Genealogy as a hypothesis

“Genealogy” is a provisional way to ask about relationships, overlap and change. It does not mean the project has reconstructed a true musical family tree.

Several distinct relations must be kept separate:

| Relation | Evidence it would need |
|---|---|
| Acoustic proximity | Defined recordings, representation, distance and reproducible processing |
| Perceived musical relationship | Independent judgments on the exact material, understandable questions, reliability and held-out validity |
| Historical influence | Documentary or other independent historical evidence; dates alone are insufficient |
| Future preference change | Repeated liking and opportunity/exposure, independently measured relations, strong baselines and future held-out tests |
| Causal guidance | An appropriately reviewed voluntary intervention and a design that identifies its causal effect |

One layer does not automatically establish the next. Shared features can make two models agree without creating independent evidence. A change in a symbolic score need not create an equally audible change for a listener. A graph edge is neither an explanation of culture nor permission to influence a person's preferences.

Independent perceptual validation, longitudinal validation and historical validation remain open. The public illustration is intentionally synthetic and is not used to test these hypotheses.
